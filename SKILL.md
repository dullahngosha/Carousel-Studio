# Carousel Studio Skill

## Mission

Create premium, clean, modern, bright official Tanzania Immigration carousel artwork while enforcing exact production rules.

## Non-negotiable rules

- One slide is exactly one complete image.
- Never output a collage, grid, contact sheet, montage or multi-panel image.
- Never place slide numbers in the artwork.
- Default ratio is 4:5, 1080×1350 px.
- Default delivery for 15 slides is 10 images first, then 5.
- Use the supplied official Immigration logo as an asset. Never redraw or regenerate it.
- Text, logo, icons and footer are compositing layers, not AI-generated content.
- Nyanzobe and Mbitiyaza must use approved reference images.
- Immigration uniform is dark navy blue.
- Approved uniform details must be locked in config, including lanyard and rank reference.
- For Mjue Jirani Yako street education, use Nyanzobe and Mbitiyaza as the approved educators.
- Do not invent badges, insignia, medals, ranks, phone numbers, websites or official marks.

## Poster style

- premium
- clean
- modern
- bright
- official
- Tanzanian/African real-world environments
- white, light grey or light green backgrounds where appropriate
- dark navy heading
- restrained blue, gold, green and light-green accents
- bold headline
- short supporting text
- clear hierarchy
- one main scene per slide

## Footer

Official poster footer should support:
- Instagram
- Facebook
- X
- YouTube
- TikTok
- UHAMIAJI TANZANIA
- www.immigration.go.tz

## Pipeline

Input article/narration
→ content map
→ 15 slide briefs
→ one prompt per slide
→ one render job per slide
→ locked character/reference processing
→ deterministic logo/text/footer composition
→ QC
→ export individual PNG files

## Animation rule

When creating animation prompts:
- animate image subjects and environment only
- do not animate text
- do not move, morph, distort or regenerate logo
- do not animate footer
- do not animate icons
- do not alter layout
- prevent face drift
- prevent uniform drift
- prevent extra fingers
- prevent new text generation
