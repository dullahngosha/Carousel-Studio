# QC Policy

A slide is rejected if any hard rule fails.

## Machine checks
- file exists
- PNG output
- exactly 1080x1350
- unique output path
- required official assets present before production
- prompt guard passes

## Visual review checks
- exactly one complete poster scene
- no collage/grid/split screen
- no slide number
- no cropped face, logo, headline or footer
- correct approved character identity
- Immigration uniform dark navy blue
- lanyard present where required
- no invented insignia
- official logo is the supplied asset, not generated
- all five social icons present
- UHAMIAJI TANZANIA present
- www.immigration.go.tz exact

Visual checks remain mandatory because image dimensions alone cannot prove that an image is not a collage.
