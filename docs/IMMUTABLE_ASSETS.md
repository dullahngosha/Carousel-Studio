# Immutable Official Assets

The Tanzania Immigration logo and Tanzania National Coat of Arms are immutable production assets.

## Absolute rule
When either mark is displayed, Carousel Studio must place the original supplied image file as a compositor layer. The generative model must never draw, recreate, repair, vectorize, recolor, stylize, simplify or approximate it.

The same rule applies to approved Tanzania passport references and the Mjue Jirani Yako campaign logo when exact identity is required.

## Character references
Mbitiyaza and Nyanzobe have separate approved references for uniform and Mjue Jirani Yako field clothing. Uniform scenes require dark navy blue. A lanyard is required even where an older source reference lacks one; the lanyard is an explicit project styling requirement and must not alter the approved face identity.

## Failure behavior
If an exact required asset is unavailable, stop production and report the missing asset. Never substitute a generated lookalike.
